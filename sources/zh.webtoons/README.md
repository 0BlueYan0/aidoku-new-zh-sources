# WEBTOON 繁體中文

提供官方 App 的完整章節清單，支援免費、試閱，以及登入帳號已購買或已解鎖的內容。首頁、搜尋、分類與作品詳情使用官方網站資料，保留既有書庫的章節識別與閱讀進度。

已取得權限的章節保留原始名稱。購買、代幣扣款、觀看廣告與取得限時解鎖資格，請在官方 App 完成，再回 Aidoku 重新整理作品。

## 登入與閱讀

需要 Aidoku 0.9.0 以上；網頁登入需要 iOS 17 以上。

來源設定 → 登入 → 在官方頁面完成登入。帳號資訊會顯示名稱；若登入頁未自動關閉，請關閉後按「同步登入狀態」。來源只保存驗證成功的登入工作階段，不保存密碼。

登入失效時，請先登出再重新登入。網路暫時失敗不會清除登入狀態。登出會清除來源保存的登入資料與來源專用的網站 Cookie。

未登入的一般免費條漫可直接使用網頁閱讀。App 服務暫時無法使用時，作品詳情仍保留網頁資料，有公開閱讀連結的章節會嘗試網頁閱讀；App 專用內容仍需服務確認權限。章節清單更新失敗時，不以不完整清單覆蓋書庫。
