# WEBTOON 繁體中文

第 20 版修正同步成功後被誤登出：登入與登出通知依 Aidoku 的登入設定判斷，不再用時間標記猜測。延遲或重複通知不會清除已驗證的工作階段；空 Cookie 回呼也不會讓 App 把登入設定移除。

第 19 版加入官方網頁登入、帳號狀態與已購買章節閱讀流程。密碼只交給官方登入頁；來源保存驗證成功的登入工作階段，不保存密碼。

沿用第 18 版的完整 App 章節清單、免費／試閱閱讀、實際閱讀方向及既有章節主鍵。付費章節保持可點擊，以便閱讀前重新驗證剛取得的購買權限。購買、觀看廣告及取得限時解鎖資格仍須在官方 App 完成。

## 登入與登出

來源設定 → 登入 → 在官方頁面完成登入。登入頁應自動關閉，帳號資訊顯示名稱；若沒有自動關閉，關閉登入頁後按「同步登入狀態」。

登入必須通過 App API 的 getMemberInfo 才會被接受。登入失效會停止自動重試並提示重新登入；網路暫時失敗不會清除登入狀態。登出清除來源保存的工作階段及來源專用網頁 Cookie，並嘗試送出官方網站登出請求。

需要 Aidoku 0.9.0 以上及 iOS 17 以上。帳號登入後的實際購買權限與付費圖片仍需使用者以自己的帳號完成下列實機驗證；離線測試的模擬帳號資料不代表已驗證真正帳號登入。

## 自動驗證

在本目錄執行：

```powershell
cargo test --locked
cargo test --locked --features live-tests
cargo clippy --locked -- -D warnings
cargo clippy --locked --tests --features live-tests -- -D warnings
```

live-tests 只發出匿名唯讀請求，驗證完整清單、一般條漫閱讀與 MANGA 試閱圖片。其他測試涵蓋登入 Cookie 篩選、登入／登出通知、舊請求失效隔離、購買權限、到期與圖片 token；不需要或包含任何真人帳號。

在專案根目錄打包：

```powershell
aidoku package sources/zh.webtoons
aidoku verify sources/zh.webtoons/package.aix
```

## 實機清單

1. 更新為 v19，從多工畫面關閉 Aidoku 再重開。
2. 未登入時確認免費／試閱可讀；未購買集數不會出現假文字頁或被誤算已讀。
3. 使用與官方 App 相同的帳號登入，確認帳號資訊顯示名稱。
4. 重新整理有已購買集數的作品，確認標示「已購買」，實際開啟圖片。
5. 同一作品未購買的集數仍不能閱讀；免費／試閱仍正常。
6. 一般條漫的已購買集數與 MANGA 已購買集數分別測試，確認圖片及閱讀方向。
7. 從多工關閉再開啟，確認登入與已購買閱讀持續有效。
8. 登出後重新整理作品並重開已購買集數，確認權限已撤回、帳號資訊清空；免費內容仍可讀。
9. 登入另一個帳號，確認已購買標示與可閱讀範圍依新帳號更新。
10. 登入失效時確認提示重新登入、不重試卡住；退出後重新登入可恢復。
11. 確認 v18 既有書庫進度、深層連結、首頁、搜尋、分類與設定頁無回歸。

## 實作依據

- Android 3.9.13 的 HMAC-SHA1 簽章、固定每頁 30 筆的 titleHomeEpisodeListV3。
- NEO_SES 與 NEO_CHK 只由來源專用的官方網站 Cookie 取得；App API 的 NEO_SES 依 Android 行為加引號。其餘網站、帳號服務或追蹤 Cookie 不會轉送。
- 已購買權限來自 productRightList.json，閱讀由 episodeInfoWithLogin.json 再次檢查。普通付費條漫與 MANGA 都按 App 的 product 欄位取得圖片 token。
- 圖片 token 不保存於來源設定，每次重新取得頁面清單時更新，且只轉送至官方專用圖片主機。
- 章節總數、分頁錯誤與主鍵保存沿用 v18 的保護，失敗不以不完整清單覆蓋書庫。
